# Heath Huang — Portfolio

Interaction and visual design portfolio. Built with HTML, CSS and JavaScript.

## View the portfolio

https://heath10086.github.io/heath-portfolio/

## Local preview

Open this folder in VS Code and use Live Server, or run:

```sh
python3 -m http.server 5173
```

Visit http://localhost:5173. Use an HTTP server because the site uses JavaScript modules.

## Structure

- `index.html`: selected work
- `about.html`: profile and design philosophy
- `project.html`: project case studies
- `css/`: visual system, responsive layouts and refinements
- `js/`: content, page rendering and motion
- `assets/`: project images, favicon and locally hosted fonts

The site uses relative paths and can be hosted with GitHub Pages. Future project slots are explicitly marked as coming soon.
